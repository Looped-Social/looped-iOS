# Looped iOS

Workplace-verified social app. SwiftUI MVP.

## Tech Stack

iOS 15+ | SwiftUI + Combine
Swift 5.7+ | MVVM Architecture
Backend: TBD

## Setup

```
bash
git clone https://github.com/yourusername/looped-ios.git
cd looped-ios
```

Build and run with `Cmd + R`

## MVP Features

 - Authentication & company verification
 - Company feed with posts
 - Basic reactions
 - Reporting/moderation
 
## Project Structure

```
├── Models/          # User, Post, Message, Notification
├── Views/           # Feed, Messages, Profile, Settings
├── Services/        # Auth, Posts, Messages, Push
└── Protocols/       # Shared interfaces
```
